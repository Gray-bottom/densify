DENSIFY · 密排
==============

双击「启动压缩工具.bat」打开，不需要安装任何东西。

第一次打开会先看到一页介绍，看完点「选择文件」或右上角「跳过」即可。
之后想再翻开，点左上角那个橙色图标就行。

一、能做什么
------------
把 PDF、图片（jpg / jpeg / png / bmp / webp / tif / gif）压到指定大小，
输出成 jpg、png 或 pdf。可以一次处理一批，每个文件都能单独设大小。

全部在本地完成，不联网，不上传。

二、基本流程
------------
1. 点右上角「添加文件」，或按 Ctrl+O
2. 填默认目标（默认 200 KB），选输出格式
3. 确认输出目录（默认在桌面\压缩输出）
4. 点「开始压缩」

压完会问要不要打开目录。右上角一直有个「打开目录」按钮，
随时可以去看结果，不用等压缩结束。

三、几个值得知道的功能
----------------------

【每个文件单独设大小】
列表里「目标」这一列，双击就能改。想让成绩单 200KB、推荐表 300KB，
就分别双击那两行的「目标」填不同数字。留空表示跟随上面的默认目标。

填的时候可以带单位：300、300KB、1.5MB 都认。

【看压缩效果】
双击任意一行（除了「目标」列），会弹出对比窗口：
左边原图、右边压缩结果，底部写着大小变化和减小比例。
压之前也能点开，只是右边显示「尚未压缩」。

这是判断"压到这个体积到底糊不糊"最直接的办法。
不满意就换个格式或者放宽目标再压一次。

【右键菜单】
在文件上点右键：查看对比、设置目标、从列表移除。
在列表空白处右键：添加文件、添加文件夹。

【快捷键】
Ctrl+O      添加文件
Ctrl+Enter  开始压缩
Delete      移除选中的文件（要在列表里按，光标在输入框时不会误删）
Esc         关闭欢迎页

【自动格式】
输出格式选「自动」时，程序会对同一个文件同时试 png 和 jpg，
挑保留像素更多的那种。省得你自己纠结。
固定选 jpg 或 png 也可以，但扫描件和截图适合的格式确实不一样（见第五点）。

【中途取消】
压到一半可以点「取消」，当前文件处理完就停，已经压好的会保留。

【记住设置】
目标大小、格式、输出目录会自动记住，下次打开还是上次的设置。
存在本目录的 config.json 里，想恢复默认删掉它就行。

四、关于大小换算
----------------
填 200 KB，程序按 200,000 字节算，不是 204,800。
因为上传系统判"200KB 以内"有两种口径，按 200,000 算两边都不会超。
想放宽就自己填 204，或者用 MB。

五、选 jpg 还是 png
-------------------
- 证书、成绩单、扫描件、照片  → jpg（压缩率高，体积小）
- 截图、表格、大量小字的图    → png（同体积下文字更锐利）

同一个文件换格式差别很大，拿不准就用「自动」。
举例：一张 Excel 表格截图，png 62KB 就能无损，转 jpg 反而要 146KB 还带毛刺。

六、输出文件命名
----------------
单页/单图      原名.jpg
多页拼接       原名_2页.jpg
多页逐页       原名_p1.jpg、原名_p2.jpg
PDF 进 PDF 出  原名_压缩.pdf

输出目录就是文件所在目录时，单图的结果会自动变成「原名_压缩.jpg」，
不会顶掉你原来那张图。原文件永远不会被覆盖。

输出目录里已经有上次的结果（比如又压了一遍），会先问一句，确认后才覆盖。

七、多页 PDF 怎么处理
---------------------
「拼接成一张」：所有页上下拼成一张长图，适合当作一份材料上传
「逐页输出」：每页单独一张，文件名带 _p1、_p2

输出格式选 pdf 时这个选项不起作用。

八、几点说明
------------
1. 目标定得越小，清晰度损失越大。A4 一整页密集表格压到 200KB 以内，
   小字会明显发钝，这是体积限制决定的，不是工具的问题。

2. 程序优先保住分辨率，其次才降清晰度：先按原尺寸试最高质量，
   压不下来才逐级缩小，不会一上来就把图缩得很小。

3. PDF 转 PDF 时依次尝试：无损优化 → 内嵌图片重压 → 整页转成图片。
   走到第三步文字层会丢失（变成图片，不能再复制文字），日志会写明走了哪一步。

4. 输出 png 比 jpg 慢，多页扫描件单个可能要十几二十秒。
   压缩在工作线程里跑，界面不会卡住，进度条和每行的百分比都会动。

5. 界面上的 01 / 02 / 03 是面板编号，旁边 // QUEUE、// CONFIG、// LOG
   是英文功能标，左边那道橙色竖条标出当前分区，都是装饰，不影响使用。
   列表空的时候中间会铺一层点阵网格，左下角写着 RL-CMP · STANDBY。

九、如果打不开
--------------
本工具依赖 D:\miniconda3 里的 Python（含 tkinter、Pillow、PyMuPDF）。
如果那个目录被删了或换了位置，把「启动压缩工具.bat」里的路径改一下即可。
运行出错会写在本目录下的 error.log。
